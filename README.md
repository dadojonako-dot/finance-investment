# Финансы и инвестиция

Платформа для ручного учета движения фиатных и криптовалютных средств, спотовых и фьючерсных сделок, инвестиций по проектам и связанных расходов.

## Основные принципы

- Несколько независимых Ledger.
- Все финансовые движения вводятся пользователями вручную.
- Внутри Ledger создаются счета и кошельки.
- Поддержка USD, USDT, BTC, ETH и других активов.
- Ручной учет Spot и Futures сделок с автоматическим расчетом P&L.
- Учет инвестиций, доходов и расходов по проектам.
- Общий Dashboard и аналитика отдельно по каждому Ledger.
- Ролевой доступ и журнал аудита.

## План модулей

1. Авторизация и пользователи
2. Ledgers
3. Счета и кошельки
4. Ручные операции
5. Переводы между Ledger
6. Spot
7. Futures
8. Инвестиционные проекты
9. Расходы и доходы проектов
10. Dashboard и отчеты
11. Audit Log

## Предлагаемый стек

- Frontend: Next.js + TypeScript
- Backend: NestJS + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- API: REST
- Deployment: Docker
